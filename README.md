## The current workspace

- **A calmer interface:** action-first pages, Education navigation and useful
  explanations available by click, tap, hover or keyboard.
- **[Keep going, your story so far](https://zanark.github.io/CareerOS/#/perspective):**
  a newest-first journal of actual history and saved work, with month chapters,
  memory cards and expandable accounts/sources. Unknown dates stay unknown;
  reading never awards progress.
- **[Georgia Tech OMSCS](https://zanark.github.io/CareerOS/#/omscs):**
  [six specialization comparisons](https://zanark.github.io/CareerOS/#/omscs/specializations),
  online-only [course choices](https://zanark.github.io/CareerOS/#/omscs/paths),
  prerequisite-aware draft calendars and shared academic entries. Self-reports
  are not enrollment, an official degree audit or learning credit.
- **[Game Development / World Forge](https://zanark.github.io/CareerOS/#/mission/gamedev):**
  a Godot-first route from zero with 65 checkpoints, 78 study/reference units
  and 156 exercises. Starts **Planned**; browsing does not activate it.
- **An original multiplayer capstone:** Borrowed Ground includes a complete
  story, mechanics, level atlas, network/recovery contract and 100-point
  self-grading rubric. It is [your build target](docs/GAME-DEVELOPMENT.md),
  not a supplied playable game.
- **[Your actual work, in 3D](https://zanark.github.io/CareerOS/#/home):**
  mission rings, saved evidence and optional Discovery Atlas rewards, with
  a bounded daily plan and focus room. DeepSeaFoam dark and Harbor Daylight
  light retain the animated sunrise/sunset switch.

### Clearer missions, calmer focus

- **A calendar in the shared header:** month, date and weekday, a gentle paper
  turn, and a red weekend strip. Daily plan sits directly below Overview.
- **[A checkpoint that looks like a checkpoint](https://zanark.github.io/CareerOS/#/mission/pattern):**
  numbered flags, distinct stage labels, actual mission progress and next unlocks.
  Streak counting stays behind `?` help; operation documents sit at the bottom.
  Saved blockers turn their card red, while a clear card is green.
- **[See how missions work](https://zanark.github.io/CareerOS/#/missions):**
  an animated, read-only walkthrough of two missions, stages, evidence and
  checkpoint unlocks. Pause, replay or step through it; reduced motion is
  respected. **In focus** is your active planning pool; **Primary** gets first
  priority among eligible missions. The example never awards real progress.
- **[Choose a focus soundtrack](https://zanark.github.io/CareerOS/#/plan):**
  the supplied cafe thumbnail opens an optional YouTube playlist in a new tab
  from the compact timer or focus room. No embedded player, autoplay or timer reset.

### Discovery Atlas

Explore real checkpoint expeditions, saved-work EXP between
discovery unlocks, and an explicitly unearned next-chapter preview. Read the
[six-game progression investigation and tradeoffs](docs/ATLAS-PROGRESSION-RESEARCH.md).
Existing records, criteria and the Discovered default remain in charge.
The Atlas includes seven animated chapter atmospheres, a living
constellation and expressive cards, with **Pause motion** and system reduced-motion
support. Decoration never changes progress.

## Know where your progress lives

[![Progress is stored in this browser. Export a JSON backup and import it elsewhere to move devices. There is no account or automatic sync.](docs/images/readme-storage.png)](https://zanark.github.io/CareerOS/#/settings)

**[Export a backup](https://zanark.github.io/CareerOS/#/settings)** before changing devices. Imports replace the destination; backups are not encrypted.

Existing explicit records and custom choices remain authoritative. The narrowly
owner-approved academic starter is intentionally public app data; it is not
encrypted personal storage. An optional [encrypted repository journal](https://zanark.github.io/CareerOS/#/repository-sync)
supports manual cross-device publication, not automatic uploads or cloud sync.
Private PDFs, advisory reports and browser backups are not bundled.
